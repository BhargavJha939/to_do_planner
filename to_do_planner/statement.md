# Problem Statement

## Problem

It's easy to lose track of deadlines when you've got a lot going on. A plain to-do list without dates 

doesn't really help, so what I actually need is something that flags what's overdue or about to be due,
not just a list of tasks sitting there.

## Scope

* Add, edit, complete and delete tasks (title, due date, priority)
* Automatic status per task (overdue / due today / due soon / upcoming /done)
* Alerts shown on startup for overdue and due-soon tasks
* Save everything to a file so it persists between runs
* Export a summary report as a text file

## Target users

Mainly students who want a simple deadline tracker without needing to set up a whole calendar app for it.

## High-level features

1. Task management (add/edit/complete/delete)
2. Planning views (sorted list, status tags, overdue/due-soon alerts)
3. Persistence and reporting.
